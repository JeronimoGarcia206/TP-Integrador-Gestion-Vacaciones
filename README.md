Chatbot de Gestión de Vacaciones 

Trabajo Integrador - Organización Empresarial 

Descripción 

Este proyecto consiste en el desarrollo de un chatbot para la gestión de solicitudes de vacaciones de empleados. 


El sistema permite: 

Consultar empleados mediante DNI. 

Verificar días disponibles. 

Solicitar vacaciones. 

Aprobar o rechazar solicitudes según la disponibilidad. 

Validar errores de ingreso de datos. 


Tecnologías utilizadas 

Python 3 

Archivo TXT como base de datos simulada 

GitHub para control de versiones 


Ejecución 

Descargar los archivos del repositorio. 

Verificar que main.py y empleados.txt se encuentren en la misma carpeta. 

Ejecutar: python main.py
